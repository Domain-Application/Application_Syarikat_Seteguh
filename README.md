# Application_Syarikat_Seteguh

Weighbridge and trading program of Syarikat Seteguh (oil palm fruit): receiving, despatch, normal and public weighing, price update, purchase and sales invoices with MyInvois e-invoice, other-product invoices, and payroll. VC6 / MFC on the shared wlib32 framework (project `menu.dsp`).

The module reference (business view and technical view; the sister program `Application_Nibong_Jaya` has its own, with a list of differences) is in [docs/MODULE_REFERENCE.md](docs/MODULE_REFERENCE.md).
